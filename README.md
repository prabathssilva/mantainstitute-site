# Manta Institute for Mathematics — website

Source for https://www.mantainstitute.org, hosted on GitHub Pages.

- Plain static HTML/CSS — no build step needed to serve.
- `build.py` regenerates the pages from one template (shared header/footer).
- `CNAME` sets the custom domain; don't delete it.
- Old Squarespace URLs redirect via small stub pages (e.g. `about-the-founder.html`).
